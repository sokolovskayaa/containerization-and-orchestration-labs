# Базовая нагрузка на оформление заказа

Источник: итоговая сводка k6, предоставленная пользователем 30 октября 2026.
Команда: BASE_URL=http://127.0.0.1:18080 DURATION=5m k6 run
--summary-export lab4/evidence/order-load-summary.json lab4/scripts/order-load.js.

- Длительность: 5 минут; интенсивность: 5 запросов/с.
- POST /order: 1500 запросов, 1499 ответов 201 (99.933%), 1 ошибка (0.067%).
- Единственная ошибка: EOF; точная причина не установлена.
- p95 по всем HTTP-запросам: 41.87ms.
- p95 по expected_response:true: 41.37ms.
- Средняя длительность успешных ответов: 25.34ms; максимальная: 1.61s.

Доступ через kubectl port-forward svc/api на 127.0.0.1:18080. Он направляет
запросы в один выбранный под, а не равномерно во все три реплики api.
Этот прогон подтверждает успешную нагрузку на путь api → postgres в базовом
состоянии. Preemption, node-pressure eviction и SLA под перегрузкой им не
проверялись. Результаты раннего прогона на порту 8080 относятся к другому
HTTP-обработчику и не используются для оценки успешных заказов.
